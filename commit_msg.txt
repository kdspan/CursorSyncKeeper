fix: scheduled-task reliability + shutdown MouseTrails persistence + foreground-hook gating

- InstallScheduledTask now imports an explicit Task Scheduler XML definition
  (LogonTrigger + InteractiveToken + HighestAvailable, RunOnlyIfLoggedOn
  defaults true) instead of the brittle "schtasks /create /sc onlogon /rl
  highest" command line that often created a task that never launched the
  daemon. Falls back to the command line if XML import fails.
- Daemon handles WM_QUERYENDSESSION/WM_ENDSESSION to re-assert MouseTrails=-1
  before Windows snapshots per-user settings at shutdown, so a 0 left in the
  final seconds is no longer persisted (which previously booted the mouse onto
  the hardware path).
- EVENT_SYSTEM_FOREGROUND hook now only schedules a sentinel repair when
  IsLikelyFullscreenForegroundWindow() is true; ordinary foreground switches
  (Telegram, browser, explorer at logon) never touch MouseTrails and no longer
  spuriously trigger a repair.
- README: new "计划任务的功能与必要性" section (argues why Task Scheduler is
  required over Run key / service / Startup folder); documents shutdown
  persistence and foreground-hook gating.
